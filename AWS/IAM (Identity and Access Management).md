
#### Users & Groups

Groups are basically teams with certain permissions e.g. Developers, Operations - Only have permissions they need 


users or groups can be assigned JSON documents called **policies**. 
- These policies define permissions of users 

We use Least Privilege Principle. Only give permissions that a user needs.
