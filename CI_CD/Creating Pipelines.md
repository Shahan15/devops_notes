**Conditions and expression**:
- Conditions: Allow you to control when a job or step should run based on a certain criteria 
- Expression: Provide a way to perform calculation, manipulate strings, and more within a workflow file

**Matrix builds and parallel testing:**

- Matrix builds: allow you to run multiple job configuration in parallel
- Useful for testing across different environments (e.g. Python versions, operating systems)
