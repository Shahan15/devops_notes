Determining best path for data to travel across the network. Fundamental for internet functionality. For DevOps this is essential for Network performance optimisation, reliable application delivery. 

Router - This determines the best path

**Static vs dynamic routing:** 

- Static - Where routes are manually set up by network admins. Simple but not scalable.
- Dynamic - uses algorithms to find most optimal route. Automatically adjusts routes. Scalable.

**Common Routing protocols:**

These automate route determination and enhance network efficiency by automating network updates

- OSPF -Open Shortest Path First - Finds the shortest path for data to travel. Considers status of network and links.
- BGP - Border Gateway Protocol - Routes data between different autonomous systems. Which are large networks managed by a single organisation. This allows network admins to define policies. greater control
